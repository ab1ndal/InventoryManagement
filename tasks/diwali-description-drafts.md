# Diwali Edit: product description drafts

These are draft rewrites of the product descriptions for the 50 Diwali Edit products. They are for owner approval only. Nothing has been changed on the site or in the database yet.

Rules used for every draft:

- Shop voice: warm, concise, factual. One or two sentences, about 15 to 35 words, sentence case.
- Photo-caption phrasing ("This is a...", "The lehenga features...") and all markdown formatting removed.
- Only facts already in the current description or the product's fabric and variant colours. No invented work types, fabrics, occasions, included pieces or measurements.
- Variant colours are the source of truth. Where the old description guessed a different colour, the draft uses the variant colour name and a Note says so. Products with many colours describe the design instead of listing colours.
- Included pieces (salwar, dupatta, blouse, pant) are kept when the current description states them.
- Spelling fixed: sequence to sequin, brocket to brocade, Satan to satin, swarosvki to Swarovski, Banarsi to Banarasi. Moti and resham kept as is.
- At most one light touch of praise ("festive", "elegant"). No prices, supplier names or codes.
- Very thin descriptions get a minimal accurate line and a Note asking for more details.

The current text is shown exactly as stored, in code formatting. A Note appears only where a conflict was resolved or something needs checking.
